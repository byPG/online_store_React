# About the project 
Beauty Store - an online store based on React.

# Project Description
Beauty Shop is an e-commerce application designed to present the offer of an online cosmetics store.

# Functions
Planned features in the first version of the project:
- home page,
- product list,
- product categories,
- product details view,
- shopping cart,
- simple order form,
- fetching product data from Firebase,
- responsive interface.

# Technologies
- React
- Vite
- Tailwind
- CSS
- JavaScript
- React Router
- Firebase
